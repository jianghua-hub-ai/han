# IR-02 Web 前端批次计划

本计划只组织 `tasks-web-spa.md` 中已登记的 12 个 task 与依赖，不复制任务状态。

## 1. 批次总览

| 批次 | 范围 | 目标 | 退出条件 |
|---|---|---|---|
| W1 | S1.1、S1.2、S2.1、S2.2 | 地基：可构建工程 + 路由骨架 + 登出端点 + 会话客户端 | `npm ci/build/lint/test` 全绿；登出契约测试绿；会话测试绿 |

## 4. 门禁与确认点

| 检查点 | 何时 | 内容 |
|---|---|---|
| G0 读取 | 每个 task 开工前 | 读 design 对应章节 + 目标文件现状，确认契约细节（尤其 A1、A3） |
| 局部验证 | 每个 task 关闭前 | 验收命令全绿 + `gofmt`/`lint` + Lead diff 复核 |
| 独立评审 | 每批次结束 | 非作者评审；本 Host 若无 Reviewer Role，保持待审，不由作者换名自审 |
| E2E | 部署后 | 未登记，环境就绪后另立任务 |

## 5. 风险与依赖外部

| # | 风险 | 影响批次 | 处理 |
|---|---|---|---|
