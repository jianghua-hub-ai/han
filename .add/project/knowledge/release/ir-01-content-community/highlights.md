# IR-01 亮点与价值故事（内部草稿）

> 每条亮点绑定至少一项可感知载体（可运行命令 / 可量化结果 / 可完整演示的故事）。无载体内容不进入对外材料。

## 亮点 1：作者能完整管理自己的文章

- **谁**：注册作者。
- **原来遇到什么**：没有可用的文章生命周期入口，写作与撤销只能停留在设计稿。
- **现在如何完成**：注册 → 登录 → 创建 → 修改 → 删除 → 浏览，全流程由生产业务 API 承载；作者只能操作自己的文章。
- **得到什么结果**：首期最小可用闭环成立；作者侧 4 个键的投影与 16 端点中的作者路由均由契约测试锁定。
- **边界**：没有 UI；无部署后 E2E（ADR-0036）；不做评论、收藏、关注、标签。
- **载体**：`go test -tags=contract ./...` 全绿（286 run / 287 pass）；author 投影 4 键断言。

## 亮点 2：管理员能安全处置无归属文章

- **谁**：管理员。
- **原来遇到什么**：作者删除后文章无归属，若直接放开会绕过所有权与安全链。
- **现在如何完成**：`GET /api/v1/admin/orphan-articles`、`POST .../publish`、`POST .../transfer`、`DELETE ...` 四个入口；405 响应带精确 `Allow`，且 404/405 先于安全链，探针事件只允许 `trace`。
- **得到什么结果**：无归属文章可查询、恢复公开、转移或永久删除；错误方法不会触发 resolver 或业务 handler。
- **边界**：真实部署与跨系统未验证；生产恢复链未实现（ADR-0037）。
- **载体**：`TestOrphanDispositionProductionRoutes_RealHandlersEnforceSecurity` 34 叶子 PASS；`Allow` 精确映射断言。

## 亮点 3：契约与安全边界可核，减少联调返工

- **谁**：前端/调用方、测试、运维评审。
- **原来遇到什么**：接口形状、错误码、Ready/Unavailable 语义靠口头约定，联调靠试错。
- **现在如何完成**：16 端点 method/path、三投影 allowlist、19 条公共错误、S1–S16 内部端口、Ready 20 / Unavailable 6 全部由契约测试锁定。
- **得到什么结果**：普通与 `-race` 各 286 run / 287 pass；契约与源码同时变更才会通过，接口漂移会被测试捕获。
- **边界**：契约测试不等于真实部署验证；跨平台一致性未验证。
- **载体**：`go test -tags=contract ./...` exit 0（28.514s）、`go vet` exit 0、`gofmt` 0 行。

## 价值故事：一位作者的完整一天

- **角色**：新注册作者「小林」。
- **情境**：想发布一篇技术笔记，随后修改标题，最后删除草稿。
- **操作**：注册账号 → 登录获取会话 → `POST /api/v1/articles` 创建 → `PUT /api/v1/articles/{id}` 修改 → `GET /api/v1/articles` 浏览 → `DELETE /api/v1/articles/{id}` 删除。
- **结果**：文章按正交状态（发布意图 / 违规 / 归属）呈现；作者越权访问他人文章被拒绝；删除后文章按设计保留或进入无归属流程。
- **边界**：以上为契约层与进程内证据；真实部署入口与外部网络未验证。

## 不发布的候选（证据不足或边界过大）

- “高可用”“零风险”“完全自动化”：无对应证据，禁止使用。
- “生产就绪 / 灾备就绪”：ADR-0036/0037 已明确排除。
- 任何性能数字：S2.2/S2.4 未测（ADR-0033）。
