# web-spa 测试规划

本文件只规划"测什么、在哪一层、用什么环境"，不登记任务状态；task 由 `tasks-web-spa.md` 持有。

> **产出说明**：本 Host 无法拉起 `add-test-engineer` Role，本文由主会话按 `add-test-design` 产出，无该 Role 的独立产出；**本规划不代表任何测试已执行**。

## 1. 验收—风险地图

| 风险 | 可观察后果 | 影响面 | 优先级 |
|---|---|---|---|
| 会话令牌或 CSRF 落入持久化存储 | XSS 或共用设备可复用会话 | 账号安全 | **高** |
| 登出未真正终止服务端会话 | 退出后旧会话仍可访问 | 账号安全 | **高** |
| 前端自行判定可见性/所有权 | 越权展示或错误隐藏 | 数据边界 | 中 |
| 401 处理缺失导致半登录态 | 用户看到错误页面或空白 | 体验/一致性 | 中 |
| 分页游标拼接错误 | 重复/跳过条目 | 功能正确性 | 中 |
| 错误结构漂移导致提示失效 | 用户看到未处理异常 | 体验 | 低 |
| 编辑缺 ETag 导致并发覆盖 | 后写覆盖先写 | 数据一致性 | 中（待 A3 核实） |

## 3. 层次选择与理由

| 层 | 覆盖场景 | 理由 |
|---|---|---|
| 单元（Vitest） | T06、错误映射、游标拼接 | 纯逻辑，无需浏览器 |
| 组件（Vitest + Testing Library） | T01–T05、T09–T16 | 交互与状态机可在 jsdom 下证明 |
| 契约（Go `-tags=contract`） | T07、T08 | 新增端点的对外行为必须由契约锁定 |
| 集成（Go `-tags=integration` + 真实 PG） | T07 的会话撤销 | 需要真实存储验证会话失效 |
| E2E（部署后） | T17、T18 + 完整旅程 | 真实同源、Cookie、反代行为无法用 mock 证明 |

**最低足够原则**：T17/T18 只在真实部署后执行；本地不伪造同源环境来"提前通过"。

## 4. 数据与环境

| 项 | 计划 |
|---|---|
| 前端测试数据 | 组件测试使用固定 fixture（响应样本），不连真实后端 |
| 后端契约/集成 | 沿用现有 `HAN_TEST_POSTGRES_DSN` 与隔离 schema 约定 |

| 敏感数据 | 断言中不出现真实凭据；测试密码为合成值 |
