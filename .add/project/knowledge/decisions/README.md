## 引用记录规则

引用次数从各 ADR 的「引用记录」章节派生，不在此处手工计次。只读查询不写入引用记录；只有获授权的实质采用或修订才登记，并同步受影响的设计正文与索引状态。

## 编号规则

新决策编号为全部领域文件中的最大编号加一。新增稳定领域时新建领域文件并同步本索引三张表。不因框架升级自动拆分、合并或重命名既有领域文件。
