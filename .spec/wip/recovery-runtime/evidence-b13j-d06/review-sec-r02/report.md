## 3. 逐条裁决

### 3.1 `F001`（HIGH，自指死锁）→ **CLOSED**

- 死锁原链：`:1120`（旧）「unknown 未补齐前任何实施/验证卡不得启动」 × `:1117`「隔离实测由承载实现卡补证」 × `:1165`「实施/验证卡用于产出约束 8 证据」⇒ 证据只能由被禁令禁止启动的卡产出。
- r06 处置后链：`:1122` 决策接受级 = 本修订被架构与安全独立评审接受 **且** 四项决策级要素（形态/最小字段/可核判据/否证条件）齐备，达成即「只解除实施/验证卡的派发、认领与开始改动限制」；`:1124` 把 POSIX 隔离实测、ACL/GRANT 负向、真实旧备份与回执样本、独立主机复跑明写为**卡退出条件、不是启动前置**；`:1126` 生产解除仍要约束 8 全项 + 人的明确生产批准。`:1173`/`:1175` 同步收敛为同一口径，且 `:1175` 保留「本口径不放宽上段限制」。
- 安全性判断：**放行的是「写代码去产出证据」，不是「跳过证据」**。生产 unlocked 仍由约束 8 全项 + 人的批准把守，`:1126` 明确「任命与两条批准记录原件属本级证据，不因本修订被接受而视为已具备」。四项 unknown 未被读成已补齐：`:1113`、`:1120`、`:1124`、`:1128` 与 `:1188` 追溯行均逐处重申。
- 残余：`卡证据级` 混装「代码卡可产出的证据」（隔离用例、权限负向）与「必须由部署事实产出的证据」（真实旧备份、原生回执样本、独立主机复跑），而 `:1126` 又把任命/批准记录排除在一二级之外。这不构成新自指（退出条件不是启动前置），但**卡关闭时到底由谁提供哪几项**仍无归属；记为观察，不单独开 finding，建议下一轮在 `:1124` 加一句「上述证据由实施卡与部署方各自范围分列，缺失项不得由实施卡自行宣告完成」。

### 3.2 `F002`（MEDIUM，回执抗伪造）→ **CLOSED（决策级）**，残余见 `R02-F002`

- `:1118` 已增「回执还须具备抗本机伪造的真实性保证——带工具或备份系统的签名（或等价外部见证），或由独立于本次进程与 root 的外部系统产生，并含产生者身份与单调序列」，并把「可被 root 或替换后的工具单独伪造、事后重写或重建而无法验出」写入否证条件（命中即按 `restore_unknown` 处理）。

### `B13J-D06-SEC-R02-F001` — MEDIUM — 阻断生产解除，不阻断本轮

- 位置：`:1115`/`:1117`/`:1118`（决策级新增判据） × `:1133`/`:1143`/`:1146`（不变量 2/5/6） × `:1161`/`:1163`/`:1165`（解除条件 2/4/6）。

- 攻击者能力假设：不涉及攻击者；这是治理缺口：实施方按清单取证、审核方按清单验收时，新增要求无对应勾选项，导致「按字面合规但不满足 ADR 意图」。
- 要求动作：下一次获授权的 ADR-0031 修订（或本轮内允许的最小改动）在 `:1120` 或 `:1126` 加一句「本节四项判据同时构成约束 8 解除条件的必要组成，解除时须逐项取证」，并回填不变量 2/5/6 与解除条件 2/4/6；回填前，任何生产解除结论不得以「约束 8 已全项满足」成立。
- 是否阻断：阻断生产解除；不阻断决策接受级与实施卡启动。

### `B13J-D06-SEC-R02-F002` — MEDIUM — 不阻断本轮

- 位置：`:1118`。
- 问题：抗伪造要求是「签名（或等价外部见证）**或** 由独立于本次进程与 root 的外部系统产生」的弃取式，且未要求读取时验签、未规定信任锚（公钥/见证端点）固定位置与轮换主体。若实施方选「本地工具签名」分支且私钥对 root 可读，则 root 可伪造回执并自行验真，否证条件「可被 root 单独伪造而无法验出」在**本机范围内不可判定**。
- 攻击者能力假设：取得 root 或替换工具链的部署侧操作者，持有签名私钥并可控制验签程序。

- 是否阻断：不阻断本轮；阻断「回执抗伪造已可核」这一生产解除证据的成立。
