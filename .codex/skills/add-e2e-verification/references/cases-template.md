# `cases.md` 模板（用例台账 · 套件规格 SSOT · 自包含单文件）

> 落 `.spec/e2e/<suite>/cases.md`，每套件一份，**长期可迭代资产 · 纯规格层**——不含执行状态；每次执行的状态 / 证据 / issue 记在 `.spec/wip/e2e-<suite>/` 当次 run 记录（Case / Run 分层，模板见 [`runs-template.md`](runs-template.md)）。本文件只随规格变更而改，**其 diff = Step 2 重新评审信号**。
> **自包含**——默认把「执行 DAG + 物料清单 + 覆盖矩阵 + 用例明细」并入本单文件；独立 `coverage.md` / `materials.md` **仅大套件才拆**（拆分阈值：>~50 用例 / 多人分工 / 物料跨套件复用）。
> **分层定位**——本文 = 意图规格层（意图 + 三层断言点「验什么」+ 覆盖 SR + 优先级 + 物料依赖，变化慢）；详细步骤 / 选择器或调用参数 / 断言实现的 SoT 是项目选定的自动化代码（变化快），靠 **CASE-ID 双向锚定**。规格先行期（无代码）步骤先写此处作规格；代码落地后代码是步骤 SoT，此处保留意图 + 断言点。
